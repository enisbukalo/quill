# Self-check

Re-read your technical-research artifact and correct that artifact only. Verify every API, method,
signature, enum, annotation, flag, tool behavior, and validation seam against the exact version the
repository pins. Prefer repository configuration, installed source, and version-matched primary
documentation over memory. Confirm arguments, return behavior, and actual invocation paths.

Remove false certainty. Preserve anything the available evidence cannot resolve as an explicit
unknown, including what was checked. Do not invent an API or choose a solution design.
